## 三、关键结论

1. **Python 是绝对刚需**（46.8%），排第一，是所有 AI 岗位的基础。
2. **大模型/LLM（41.1%）+ Agent（30.8%）+ Prompt（14.1%）+ RAG（13.7%）** 是 AI 应用方向的核心技能栈 —— **你的两个项目正好覆盖这四项**。
3. **AI 辅助编程已成为标配**：Cursor / Claude Code 提及率 **5.2%**，MCP 提及率 **3.0%** —— 这是 2026 年的新趋势。
4. **LangChain 提及率只有 5.4%**：说明企业更看重「理解 RAG/Agent 原理」，而不是「会用某个框架」。
5. **算法岗技能（PyTorch 19.6%、深度学习 22.4%）占比高但学历门槛也高**（多要求硕士），本科应主攻 **AI 应用开发方向**。
